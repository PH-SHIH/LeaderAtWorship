# LeaderAtWorship 使用者手冊

> 版本：1.0 | 更新日期：2026-03-08

## 1. 快速開始

### 1.1 安裝

```bash
git clone <repo-url>
cd LeaderAtWorship
./setup.sh
```

安裝完成後啟動伺服器：

```bash
source .venv/bin/activate
uvicorn app.main:app --reload --port 8000
```

打開瀏覽器前往 http://localhost:8000 即可使用。

### 1.2 系統需求

- macOS Apple Silicon（M1/M2/M3/M4）
- 至少 8GB RAM（建議 16GB）
- 約 5GB 磁碟空間（ML 模型 + 音頻檔案）
- 網路連線（首次處理歌曲時需要）

---

## 2. 首頁（Dashboard）

首頁提供四個快速入口與一個 YouTube 連結輸入區。

### 2.1 快速操作：處理 YouTube 音頻

1. 在首頁的文字輸入區貼上 YouTube 連結
2. 支援一次貼上多個連結（每行一個）
3. 點擊「擷取音頻」按鈕
4. 系統會自動跳轉到處理頁面

### 2.2 導覽卡片

| 卡片 | 功能 |
|------|------|
| 歌曲庫 | 瀏覽已處理的歌曲 |
| 敬拜流程 | 編排敬拜順序 |
| 音頻處理 | 查看處理狀態 |
| 投影控制 | 啟動即時投影 |

---

## 3. 處理 YouTube 音頻

### 3.1 單首歌曲處理

1. 前往首頁或「音頻處理」頁面
2. 貼上 YouTube 連結
3. 點擊「開始處理」
4. 等待處理完成（通常需要 2-5 分鐘）

處理進度會即時更新：

```
下載音頻 (10-25%) → 人聲分離 (30-55%) → 語音辨識 (60-85%)
→ 歌詞對齊 (85-90%) → 生成字幕 (90-95%) → 儲存 (95-100%)
```

### 3.2 批次處理

1. 在輸入區域每行貼上一個 YouTube 連結
2. 點擊「開始處理」
3. 每個連結會獨立處理，各自顯示進度

### 3.3 處理完成後

處理完成後系統會自動建立：
- 歌曲記錄（標題、藝人自動擷取）
- 三個音軌（原聲、人聲、伴奏）
- SRT 字幕檔（時間軸同步）

可在處理頁面下載 SRT 字幕檔，或前往歌曲詳情頁瀏覽。

---

## 4. 歌曲庫

### 4.1 瀏覽歌曲

前往「歌曲庫」頁面查看所有已處理的歌曲。每首歌曲顯示：
- 歌曲名稱
- 藝人/團隊
- 調性

### 4.2 搜尋歌曲

在搜尋欄輸入關鍵字，即時篩選歌曲列表。

### 4.3 歌曲詳情

點擊歌曲進入詳情頁，包含：

**音頻播放器：**
- 播放/暫停按鈕
- 進度條（可拖曳跳轉）
- 音量控制
- 音軌切換（原聲/人聲/伴奏）

**同步字幕：**
- 播放時自動高亮目前字幕行
- 點擊字幕行可跳轉到該時間點

---

## 5. 字幕編輯

### 5.1 編輯字幕文字

1. 在歌曲詳情頁，將滑鼠移到字幕行上方
2. 出現編輯圖示後點擊
3. 展開行內編輯區域
4. 修改文字內容
5. 點擊「儲存」

### 5.2 調整時間戳

在編輯模式下：
1. 修改「開始時間」或「結束時間」（格式：毫秒）
2. 點擊「儲存」
3. 播放器會立即反映新的時間軸

### 5.3 新增字幕行

1. 點擊字幕行之間的「+」按鈕
2. 輸入文字和時間範圍
3. 儲存後行號自動重新編排

### 5.4 刪除字幕行

1. 在編輯模式下點擊「刪除」按鈕
2. 確認刪除
3. 行號自動重新編排

---

## 6. 敬拜流程管理

### 6.1 建立新流程

1. 前往「敬拜流程」頁面
2. 點擊「新建流程」
3. 輸入流程名稱（如「主日崇拜」）
4. 選擇日期（選填）
5. 點擊「建立」

### 6.2 加入歌曲

1. 在流程編輯區點擊「加入歌曲」
2. 彈窗顯示歌曲庫列表
3. 點擊想加入的歌曲
4. 歌曲自動加入流程末尾

### 6.3 排序歌曲

- 拖曳流程中的歌曲項目即可重新排序
- 上下拖動到想要的位置後放開

### 6.4 移除歌曲

- 點擊項目右側的刪除按鈕即可移除

### 6.5 儲存流程

- 排列完成後點擊「儲存流程」

---

## 7. 即時投影

### 7.1 啟動投影

1. 在敬拜流程編輯器中選擇一個已編排好的流程
2. 點擊紫色的「啟動投影」按鈕
3. 系統會自動開啟兩個視窗：
   - **投影視窗**（Display）— 接投影機或外接螢幕
   - **控制視窗**（Control）— 操作員使用

### 7.2 投影顯示畫面

- 全黑背景
- 白色大字顯示主要字幕
- 灰色小字顯示次要文字（如翻譯）
- 全螢幕模式：按 F11 或拖曳到投影機螢幕

### 7.3 控制面板操作

**導航按鈕：**

| 按鈕 | 功能 |
|------|------|
| 上一行 | 顯示上一行字幕 |
| 下一行 | 顯示下一行字幕 |
| 上一首 | 跳到上一首歌 |
| 下一首 | 跳到下一首歌 |
| 黑幕 | 暫時隱藏字幕（再按一次恢復） |

**流程導航面板：**

左側面板顯示流程中的所有歌曲，點擊可直接跳到該首歌。

右側面板顯示目前歌曲的所有字幕行，點擊可直接跳到該行。

目前正在投影的項目和行會以高亮色標示。

**手動輸入：**

如需投影自訂文字（如經文、公告），在輸入框輸入文字後送出。

## 8. 音軌切換

歌曲詳情頁的播放器支援三種音軌：

| 音軌 | 說明 | 適用場景 |
|------|------|---------|
| 原聲 | YouTube 原始音頻 | 一般聆聽 |
| 人聲 | 僅包含人聲 | 學唱歌詞 |
| 伴奏 | 去除人聲的伴奏 | 敬拜練唱 / 現場伴奏 |

切換方式：點擊播放器下方的 radio button，音頻會在當前位置無縫切換。

## 9. 環境設定

所有設定都在 `.env` 檔案中，使用 `LAW_` 前綴：

### 9.1 語音辨識設定

```bash
# 模型選擇
LAW_WHISPER_MODEL=mlx-community/whisper-large-v3-turbo  # 推薦
# LAW_WHISPER_MODEL=mlx-community/whisper-large-v3-mlx  # 最高品質

# 語言
LAW_WHISPER_LANGUAGE=auto   # 自動偵測
# LAW_WHISPER_LANGUAGE=zh   # 強制中文
# LAW_WHISPER_LANGUAGE=en   # 強制英文
```

### 9.2 人聲分離設定

```bash
LAW_DEMUCS_MODEL=htdemucs     # 快速（推薦）
# LAW_DEMUCS_MODEL=htdemucs_ft # 高品質（較慢）
LAW_DEMUCS_JOBS=8              # 並行數（配合 CPU 核心數）
```

### 9.3 伺服器設定

```bash
LAW_PORT=8000       # 伺服器埠號
LAW_HOST=0.0.0.0    # 綁定地址
LAW_DEBUG=true      # 除錯模式
```

## 10. 常見問題

### Q1：處理時間很長？

- 首次處理需下載 ML 模型（約 3GB），之後會快取
- 語音辨識是最耗時的步驟，依歌曲長度約需 1-3 分鐘
- 可在 `.env` 中調低 `LAW_DEMUCS_SHIFTS=1` 加速人聲分離

### Q2：找不到歌詞？

- 系統會自動搜尋線上同步歌詞
- 如果搜尋不到，會使用 Whisper 轉錄的原始結果
- 冷門歌曲或非主流語言可能找不到線上歌詞

### Q3：字幕時間不準確？

- 可以使用字幕編輯功能手動調整
- 調整 `.env` 中的對齊參數可能改善品質
- `LAW_ALIGNMENT_ANCHOR_THRESHOLD=0.55`（降低可增加匹配數量但降低精準度）

### Q4：投影畫面沒有字幕？

- 確認已建立敬拜流程並加入歌曲
- 確認歌曲有字幕檔（需先完成音頻處理）
- 在控制面板點擊「下一行」開始顯示字幕

### Q5：如何在其他裝置上使用控制面板？

- 確保裝置在同一個 Wi-Fi 網路
- 在其他裝置的瀏覽器輸入 `http://{伺服器IP}:8000`
- 伺服器 IP 可在終端機用 `ifconfig` 查看

### Q6：支援哪些語言？

- 語音辨識：支援 99+ 語言（Whisper 支援的所有語言）
- 歌詞搜尋：中文、英文、日文、韓文等主流語言
- 介面：繁體中文
