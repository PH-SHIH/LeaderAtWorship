# LeaderAtWorship 需求規格文件

> 版本：1.0 | 更新日期：2026-03-08

## 1. 專案概述

### 1.1 專案名稱
LeaderAtWorship — 敬拜字幕生成與即時投影控制工具

### 1.2 專案目標
為教會敬拜團隊提供一站式的字幕製作與投影控制解決方案，從 YouTube 影片自動產生同步字幕，並透過 WebSocket 即時投影到螢幕上。

### 1.3 目標使用者
- **敬拜主領**：編排敬拜流程、選擇歌曲
- **投影操作員**：控制即時投影、切換字幕行
- **媒體同工**：管理歌曲庫、編輯字幕

### 1.4 目標平台
- macOS Apple Silicon（M1/M2/M3/M4）
- 瀏覽器：Chrome / Safari / Firefox（最新版本）

## 2. 功能需求

### 2.1 YouTube 音頻處理（FR-001）

| 項目 | 說明 |
|------|------|
| **優先級** | P0（核心功能） |
| **描述** | 使用者輸入 YouTube 連結，系統自動完成下載、人聲分離、語音辨識、歌詞對齊、字幕生成的完整流程 |

**細項需求：**
- FR-001.1：支援單一 YouTube 連結輸入
- FR-001.2：支援多行 YouTube 連結批次處理（每行一個連結）
- FR-001.3：背景非同步處理，前端即時顯示進度百分比
- FR-001.4：處理完成後自動建立歌曲與字幕記錄
- FR-001.5：支援下載產生的 SRT 字幕檔

**處理管線：**
```
YouTube URL → yt-dlp 下載 → Demucs 人聲分離 → mlx-whisper 語音辨識
→ syncedlyrics 線上歌詞搜尋 → 錨點式對齊演算法 → SRT 字幕生成 → 資料庫儲存
```

### 2.2 歌曲庫管理（FR-002）

| 項目 | 說明 |
|------|------|
| **優先級** | P0（核心功能） |
| **描述** | 管理已處理的歌曲，提供瀏覽、搜尋、播放功能 |

**細項需求：**
- FR-002.1：歌曲列表頁，顯示所有歌曲（標題、藝人、調性）
- FR-002.2：歌曲搜尋（依標題關鍵字）
- FR-002.3：歌曲詳情頁，包含音頻播放器與同步字幕顯示
- FR-002.4：歌曲 CRUD（新增、讀取、更新、刪除）

### 2.3 伴奏音軌切換（FR-003）

| 項目 | 說明 |
|------|------|
| **優先級** | P1（重要功能） |
| **描述** | 播放器支援原聲、人聲、伴奏三軌切換 |

**細項需求：**
- FR-003.1：Demucs 分離後儲存人聲（vocals）與伴奏（accompaniment）兩個檔案
- FR-003.2：播放器顯示三個 radio button：原聲 / 人聲 / 伴奏
- FR-003.3：切換音軌時保持當前播放位置
- FR-003.4：音頻串流支援 HTTP Range 請求（支援拖曳進度條）

### 2.4 字幕編輯（FR-004）

| 項目 | 說明 |
|------|------|
| **優先級** | P1（重要功能） |
| **描述** | 行內編輯字幕文字與時間戳，支援新增與刪除字幕行 |

**細項需求：**
- FR-004.1：滑鼠 hover 字幕行時顯示編輯按鈕
- FR-004.2：點擊編輯後展開行內編輯區域（文字、開始時間、結束時間）
- FR-004.3：儲存後透過 API 更新資料庫
- FR-004.4：支援插入新字幕行（自動重新編號）
- FR-004.5：支援刪除字幕行（自動重新編號）

### 2.5 敬拜流程管理（FR-005）

| 項目 | 說明 |
|------|------|
| **優先級** | P0（核心功能） |
| **描述** | 編排敬拜流程，排列歌曲順序 |

**細項需求：**
- FR-005.1：建立新流程（名稱、日期、備註）
- FR-005.2：從歌曲庫加入歌曲到流程中
- FR-005.3：支援非歌曲項目（禱告、讀經、宣告）
- FR-005.4：拖曳排序流程項目
- FR-005.5：儲存與更新流程
- FR-005.6：刪除流程

### 2.6 即時投影（FR-006）

| 項目 | 說明 |
|------|------|
| **優先級** | P0（核心功能） |
| **描述** | WebSocket 即時同步的投影系統，分為顯示端與控制端 |

**細項需求：**
- FR-006.1：從敬拜流程一鍵啟動投影（建立 Session，開啟 Display + Control 視窗）
- FR-006.2：**顯示端**（Display）— 全黑背景 + 白色字幕文字，接投影機使用
- FR-006.3：**控制端**（Control）— 操作面板，顯示流程列表與字幕行列表
- FR-006.4：上/下一行字幕切換
- FR-006.5：上/下一首歌曲切換
- FR-006.6：點擊跳轉到指定歌曲或字幕行
- FR-006.7：一鍵黑幕（暫時隱藏字幕）
- FR-006.8：手動輸入自訂文字投影
- FR-006.9：支援雙語顯示（主要文字 + 次要文字）
- FR-006.10：啟動時自動載入流程中所有歌曲的字幕資料

### 2.7 智慧歌詞對齊（FR-007）

| 項目 | 說明 |
|------|------|
| **優先級** | P1（重要功能） |
| **描述** | 將線上搜尋到的歌詞與 Whisper 轉錄結果精準對齊 |

**細項需求：**
- FR-007.1：自動搜尋線上同步歌詞（syncedlyrics）
- FR-007.2：智慧搜尋策略（嘗試不同關鍵字組合、簡體轉換）
- FR-007.3：錨點式動態規劃演算法對齊
- FR-007.4：品質門檻控制（信心度、匹配率）
- FR-007.5：對齊結果標記來源類型（anchor / interpolated / extrapolated / phantom）
- FR-007.6：支援繁體中文輸出

## 3. 非功能需求

### 3.1 效能需求（NFR-001）

| 項目 | 指標 |
|------|------|
| 頁面載入 | < 2 秒 |
| WebSocket 延遲 | < 100ms |
| 音頻串流 | 支援 HTTP Range 請求，即時播放 |
| 背景處理 | 不阻塞 Web 伺服器 |

### 3.2 相容性（NFR-002）

| 項目 | 需求 |
|------|------|
| 作業系統 | macOS 13+ (Apple Silicon) |
| Python | 3.10+ |
| 瀏覽器 | Chrome 90+, Safari 15+, Firefox 90+ |

### 3.3 可用性（NFR-003）

- 中文介面（繁體中文）
- 直覺的操作流程，不需額外訓練
- 投影控制端支援鍵盤快捷鍵

### 3.4 資料儲存（NFR-004）

- SQLite 資料庫（單機部署）
- 音頻檔案存放於本地 `data/` 目錄
- 支援 Alembic 資料庫遷移

### 3.5 安全性（NFR-005）

- 本地部署，僅在 LAN 內使用
- 無使用者認證需求（信任網路）

---

## 4. 系統限制

| 限制項目 | 說明 |
|---------|------|
| 硬體 | 需要 Apple Silicon Mac（mlx-whisper 依賴） |
| 網路 | 首次處理需要網路（下載 YouTube、搜尋歌詞） |
| 儲存 | 每首歌約 50-200 MB（原聲 + 人聲 + 伴奏） |
| 並行處理 | 單一處理管線（不支援同時處理多首歌） |
| 資料庫 | SQLite 不支援高並發寫入 |
